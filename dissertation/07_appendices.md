**Sum of all 40 scores (ΣX):** 884

### Step 2: Calculation of the Mean

$$M = \frac{\sum X}{N} = \frac{884}{40} = \boxed{22.10}$$

### Step 3: Calculation of Deviations and Squared Deviations

For each of the 40 scores, the deviation `x = X – M` and `x²` were computed. The sum of the squared deviations was found to be:

$$\sum (X-M)^2 = \sum x^2 = 532.40$$

### Step 4: Calculation of the Standard Deviation

$$\sigma = \sqrt{\frac{\sum x^{2}}{N}} = \sqrt{\frac{532.40}{40}} = \sqrt{13.31} = \boxed{3.65}$$

### Step 5: Comparison with Computed Value

| | **Boys – Technical Area** |
|:---|:---:|
| N | 40 |
| ΣX | 884 |
| Mean (M) | **22.10** |
| Σx² | 532.40 |
| Variance (σ²) | 13.31 |
| Standard Deviation (σ) | **3.65** |

These values match Row 7 of **Table 4.4** in Chapter IV.

### Step 6: Use in the t-Test (with Girls' Technical Score)

Girls' Technical area: M = 14.62, σ = 4.16, N = 40 (from Row 7 of Table 4.5).

$$\text{S.E.}_D = \sqrt{\frac{(3.65)^{2}}{40} + \frac{(4.16)^{2}}{40}} = \sqrt{\frac{13.32}{40} + \frac{17.31}{40}} = \sqrt{0.333 + 0.433} = \sqrt{0.766} = 0.875$$

$$t = \frac{M_{Boys} - M_{Girls}}{\text{S.E.}_D} = \frac{22.10 - 14.62}{0.875} = \frac{7.48}{0.875} = \boxed{8.54}$$

This is the value reported in **Table 4.13** of Chapter IV. The same procedure was followed area by area to obtain all the nine t-values reported in the consolidated Table 4.21.
